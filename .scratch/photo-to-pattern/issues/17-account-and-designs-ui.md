# 17: 账号入口与设计列表 UI

- Status: open
- Blocked by: 15, 16

## 目标

/designs 设计列表页与页头账号菜单，接通同步状态展示。

## 范围

- /designs：网格列表（缩略图、名称、尺寸、更新时间、同步状态角标：已同步/未同步/冲突）；新建（进入工作台）；打开；重命名（内联，≤100 字）；删除（二次确认；云端删除走墓碑）；空态与引导。
- 页头账号菜单：登录态（邮箱、验证状态+重发、修改密码入口、注销入口、退出登录）；游客态（登录/注册）。
- 修改密码对话框（当前密码+新密码，接 T14）。
- 同步状态 UI：手动重试按钮；「已在其他设备更新」提示条。
- 数据获取：SWR/原生 fetch + 乐观更新；失败重试与错误兜底。

## 不含

- 色板管理（T18）。

- spec §F8、§F9、§F11；边界 E35–E37（UI 呈现）。

- [ ] 与 T16 引擎联动的集成测试（假云端）。
