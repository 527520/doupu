## 已批准的设计合同

温暖活泼的手作空间；允许重排信息层级；动感轻快有触感。全站统一，后台保持高信息密度。业务、权限、图纸、同意、危险操作确认不变。只本地提交，不 push/deploy/访问生产；不读写或提交 docs/marketing/。

- 纸白 #FAF8F4、深墨 #292633、辅助文字 #68616C、莓果 #B93E62、叶绿 #497367、蜂蜜黄 #E7B85C；黄色不作浅底文字。
- 少量首页/豆社宣传标题使用寒蝉全圆体；正文/作品名/表单/后台使用 Noto Sans CJK SC 真实字重。同源 WOFF2 固定版本/许可/校验，UI 子集优先、扩展汉字 unicode-range 按需加载。字体缺失必须失败，不容忍 404。
- 手机标题 28–32、区块标题 20–22、正文 15–16、辅助字 13px，输入框至少 16px。保留品牌标志；等宽字体仅用于数据/编号。
- 基础控件统一状态与触控面积，导航文字加箭头、正文链接保留下划线。透明边框不再被全局覆盖。
- 首页顺序：品牌账号 → 完整紧凑同意提示 → 两行标题/说明 → 选图/空白起稿 → 续作（预览 >=88px，仅一次操作）→ 豆社 → 帮助。390×844 首屏完整显示选图。不伪造作品。
- 豆社合并介绍，排序分段控件，高级筛选手机底部面板；保留 GET/应用/清除/返回。详情突出图纸与制作操作，许可明确、举报收纳。
- 色板完整颜色在桌面侧栏/手机底部面板展示，不撑高相邻卡片。登录去掉窄屏无意义空白。
- ResponsiveSelect 基于 react-aria-components；小接口：label/name/options/value/defaultValue/onValueChange/disabled/required/error。桌面锚定弹层，<768px 底部面板，最高可视区域70%，12项以上搜索，当前项定位，取消不改变，恢复焦点。迁移全部 select；原生仅无 JS 降级。布尔开关、短模式分段选择。
- 按下90ms/回弹160ms、选择180ms、面板220ms；减少动态关闭位移弹性。不能重挂 Canvas、重置缩放/撤销/任务，不能延迟焦点和背景释放。
