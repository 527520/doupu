## 专项与问题闭环

- 字体固定来源、OFL、派生家族改名、离线 WOFF2、分段 unicode-range 和版本化缓存 URL；资源缺失/篡改会使检查失败。字体 404 白名单已删除。
- 第一轮专项 18/18（三浏览器）通过：实际字体加载、五宽度首页、无 JS GET 降级、筛选应用/取消/返回、面板不撑高卡片、焦点恢复、长列表搜索、长中文标题与失败重试。
- 扩展至前后台五宽度时，截图自审发现登录等待正则可误匹配 `?next=`；改成实际 pathname 断言并重新生成后台证据，旧一轮后台图片不作为验收。
- Safari/WebKit 鼠标打开面板没有原生按钮焦点：入口使用 React Aria Button，三浏览器关闭恢复原入口通过。
- Firefox 卡片尺寸的 DOMRect 浮点误差为 0.00003px：比较渲染 CSS 像素，不改变“不撑高卡片”的要求。
- axe 在面板进入透明动画中测量会得到过渡颜色：等待进入状态结束后检查；不删除对比度规则或降低等级。
- 新增合法 80 字连续英文标题，通过本地授权批次 API 创建与发布，验证五宽度文本不裁切；reduced-motion 检查实际无位移矩阵，三浏览器 3/3 通过。
- 前后台扩展专项 34 通过、2 个既有条件跳过，实际待审预览、批次、人员、豆社、登录、色板均覆盖五宽度；独立待审花朵样本不依赖其他测试是否已批准原样本。
- 全量交叉运行发现启动期增加待审样本会污染旧治理测试的“队列清空”前提。未降低该断言：改为视觉用例自己的作者浏览器上下文通过真实投稿页面创建样本，启动期不额外插入待审作品；权限和审核业务代码不变。发现后的完整试跑已主动中止，不计为通过轮次。
