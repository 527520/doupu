## 验收标准（每条票通用）

1. 全量单测通过（当前 464 例，只增不减）；
2. Playwright E2E 三浏览器（Chromium/Firefox/WebKit）全绿，改动涉及的页面补 E2E 用例；
3. `npm run typecheck` / `npm run lint` / `npm run build` 全绿；
4. 我人工走查改动路径的全部边界（含：未登录/已登录、手机 350px 与桌面 1280px、断网/慢网、非法输入、空状态、错误状态、并发/双击、刷新恢复、跨设备同步）；
5. 每次提交附带改动说明；全部完成后用户整体验收。

## 关键风险与边界条件

- **视觉升级不得破坏既有功能**：所有交互流程（上传→裁剪→生成→编辑→导出→保存→同步）的按钮文案/可访问名（getByRole 依赖）保持不变，仅改样式；改动后必须跑全量 E2E。
- **配置化不做管理界面**：配置 = 环境变量 + `src/lib/config.ts` 单一出口（含默认值），`.env.example` 同步更新；服务端读 process.env，客户端不可见敏感项。
- **HEIC 兜底**：heic2any 体积较大，动态 import 按需加载；转换期间显示进度；失败回退现有友好错误。
- **Worker 化**：`generatePattern` 是纯函数（输入像素缓冲+参数+色板 → 输出图纸），用 `new Worker` 或 Comlink 轻封装；jsdom 单测不受影响（保持同步入口供测试）；取消 = 丢弃结果 + 版本号防旧结果覆盖。
- **CSP nonce**：Next.js 15 需在 middleware/headers 注入 nonce，App Router 下实现复杂度高——若实施中发现与 RSC 载荷冲突，退回「保持 unsafe-inline + 文档说明」，并把该票标记为完成（注明原因），不阻塞其他票。
- **备份告警**：失败通知渠道依赖 SMTP（已配置）；未配置时降级为容器日志显著标记。
- **字体子集**：生成常用字子集（GB2312 一级字 + 项目全部文案用字扫描），保证现有 PDF 文案不缺字；兜底保留全量字体下载路径（env 开关）。
