# 全站 UI 重构与豆社反爬

Status: ready-for-agent
Completion: in-progress
Baseline: 105beea

## 背景与目标

用户在 R12 验收后指出：按钮多为「彩色小字」、首页大红块、豆社详情右栏堆叠、官方批量页难用且缩略图失真、管理后台整体原始、原生日期选择器、评论不该可编辑、豆社缺反爬。本轮在**保留 D48 色板与字体**的前提下重做组件层与页面结构，并补齐豆社的限流与内容分级。

## 已批准的设计合同

- **令牌不变**：纸白 `#FAF8F4`、深墨 `#292633`、辅助 `#68616C`、莓果 `#B93E62`、叶绿 `#497367`、蜂蜜黄 `#E7B85C`；Noto Sans CJK SC 正文、寒蝉全圆体仅宣传标题。
- **用色纪律**：莓果只做线与点——每个视区最多一个实心主按钮、选中态、徽标、焦点环；大面积只用白与纸白；叶绿=成功/已发布/已拼，蜂蜜黄=精选/警示，砖红=破坏性。不再有大面积莓果底色。
- **签名元素**：钉板与豆粒。落区、空态、拖放面用极低对比的钉板点阵纹理；纯图标操作统一为圆形「豆粒按钮」（36–40px 细环，hover 中心填色，选中态实心莓果 + 内环高光）。点赞是一颗会「烫实」的心形豆。
- **按钮语法**：`Button`（`variant: primary | secondary | quiet | danger`，`size: sm | md`，可带图标）、`IconButton`（豆粒态，必须 `aria-label`）。文字类操作一律带图标或升级为 quiet 按钮，不再出现无边框彩色小字；删除=垃圾桶、点赞=心、举报=旗、编辑=铅笔、查看=眼。
- **结构**：去掉不承载信息的装饰（后台导航编号、随处横线）；折叠只用于真正次要的信息；空态是邀请；错误说清原因与修法；动作命名前后一致。
- **字阶**：13 / 14 / 15 / 16 / 20 / 24 / 32；等宽只给编号与数字；后台 14px 基准。
- **后台**：保留 10 个模块与全部 API，重做外壳与共享组件，新增总览页；后台不弹统计同意横幅。
- **官方批量**：分步流程（选图 → 参数与裁剪 → 生成 → 核对与发布），缩略图改服务端带格线 PNG，允许选择制作规格与色板/套装档位。
- **反爬**：公开 GET 按 IP 节流 + `Retry-After`；写接口补限流；sitemap 分页与近期截断；游标 HMAC 签名；匿名访客看服务端渲染大图（格线/板缝、无色号）与统计，色号网格、交互查看器、「用这张制作」需登录。

## 不变量

- 业务、权限、图纸协议、同意条款、危险操作确认（理由 ≥3 字 + 确认）不变。
- 所有界面文案只从 `src/messages/zh-CN.ts` 引用；E2E 依赖的 `getByRole` 名称跟随文案。
- 浏览器代码不直接调用 `crypto.randomUUID`；不新增运行时依赖（`@internationalized/date` 已在依赖树中，允许显式声明）。
- 原生控件只作无 JS 降级；不写破坏性数据库迁移（评论编辑相关列停写保留）。
- 只本地提交，不 push / deploy；不读写 `docs/marketing/`。
