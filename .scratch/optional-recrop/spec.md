# 整图首版预览与可选重新裁剪

Status: accepted
Baseline: 40787e3

## 授权与边界

用户通过侧会话明确批准：选图后以整图自动生成首版；预览旁提供可操作的「裁剪图片」，确认后自动更新。仅改此流程及移动适配，不扩展其他 UX 提议。不 push、deploy、访问生产，不读取/修改/提交 docs/marketing。

## 可观察验收

- 新图片无需裁剪确认即可看到完整图片生成的图纸；不猜测人脸/主体。
- 裁剪是预览旁的次级文字操作。调整选框不写图纸；取消保留图纸/手工编辑；确认自动重生成，有手工修改时先确认，拒绝不丢数据。
- 原图只留在当前浏览器会话的解码资源中；新设计、导入、切换设计、失败和卸载释放资源；持久化仍仅有最大 800×800 本地生成源。不把缩小源冒充可重新裁剪的完整原图，缺原图提示重新选图。
- 同时只处理一次图片操作；迟到解码/恢复/裁剪结果不得覆盖已切换的设计；失败/取消不破坏已有图纸。
- 新裁剪生成源暂存至生成成功；图纸、源及裁剪框在失败/取消/撤销时一起还原。无源旧图撤销后仍无源，冲突副本也必须执行对应清源。
- 350/390 px 与横屏下，裁剪画布有界等比、主要控件至少 44 px、底部动作和安全区可见；单指操作仅在画布内编辑选框，多指/取消不意外修改；键盘、焦点与浏览器缩放可用。

## 实施与验证

1. TDD：整图自动预览 → 重新裁剪/取消 → 编辑保护 → 异步与资源生命周期；复用已有解码/生成会话，不改图纸与存储协议。
2. 复用 Modal 焦点隔离，手机全屏裁剪、桌面有界对话框。视觉沿用奶油白 #f8f7f4、莓果红 #a83f68、墨紫 #302938、丁香紫 #756a8c、鼠尾草绿 #1e794c；宋体标题、现有自托管正文、坐标等宽。唯一视觉重点是实际图片及其裁剪框，不增加装饰。
3. 单元/组件回归与三浏览器真实 Worker E2E，移动浏览器模拟 350/390 px、横屏、触控、取消和确认，检查隐私与有界生成源；lint/typecheck、全量测试、构建、双轴 review 后本地提交。

手机布局：标题/比例 → 尽量占满余下高度的图片 → 坐标/提示 → 安全区内的取消与确认更新。草稿框只影响选择；提交时才跨越生成接口。法律、生产与真机验证仍不在本次范围。

## 设计稿阅读与本轮任务成本

已实际阅读侧会话补发的 UX 摘要、项目外 `doupu-design-v1/index.html` 全文与 README，查看桌面首页、手机首页、桌面工作台三张截图。侧会话读取接口返回 `ephemeral threads do not support thread/turns/list`，未将交接摘要冒充聊天全文。

采用其中「先给可靠默认结果，低频操作按需展开」的方向；不把 8 个原型视图、演示作品、简化引擎、未展开的后台模块或其他 UX 建议视作已授权实现。本轮不做全站换肤，不改变社区引用、投稿、分享或账号语义。

点击数以页面已打开为起点，只计应用内按钮，不计系统文件选择器和拖动选框：

| 当前范围的任务 | 应用内点击 | 保留的必要操作 |
| --- | --- | --- |
| 新图生成首版 | 1 次选图入口；选定文件后 0 次 | 自动使用整图，无强制裁剪确认或额外生成按钮 |
| 按需再裁剪 | 2 次：打开裁剪、确认并更新；比例快捷键按需另计 | 草稿调整不立即覆盖图纸，明确确认才重生成 |
| 放弃裁剪 | 2 次：打开、取消 | 取消保留原图纸和手工修补，也支持 Escape |
| 覆盖手工修补 | 再增加 1 次覆盖确认 | 防止自动生成静默丢失手工修改；拒绝不修改 |
| 恢复整图范围 | 2 次：打开、使用整张图片 | 一步重置并确认整图，不要求精确拖回四边 |

预览只新增「裁剪图片」次级入口；无原图时禁用并显示真实缺源说明与「重新选择图片」。比例快捷键避免手机精确拖拽；底部只保留取消、使用整张图片、确认并更新。重新选图的返回按钮和替换确认保护已有设计；进度取消、失败提示等沿用真实状态，不常驻伪造恢复操作。其他页面未改，不在此宣称点击数优化。
