# 页面动作与点击数验收

基线 `7a345e1`。相同动作的桌面/手机副本合并列出；下表覆盖任务按钮组，不把开发指示器列为产品控件。点击数来自 verification 的本地浏览器旅程，输入文字和系统文件选择器内部操作不计入；文件选择器入口是否计入另列。

## 核心任务

| 起点 → 结果 | 点击数及边界 |
| --- | --- |
| 首页最近设计 → 对应编辑/跟拼 | 1；依据已有兼容进度，不猜测损坏或读取失败的记录 |
| 设计卡片 → 指定图纸 | 1；云端卡先下载确认，本机落盘失败不跳转 |
| 首页选图 → 自动整图首版 | 1 次打开文件选择器；选中文件后自动生成，不含系统选择操作 |
| 现有首版 → 可选裁剪更新 | 打开裁剪 + 确认 2；修改选区手势另计；已有手工修改时保留额外覆盖确认 |
| 豆社详情 → 独立私人副本 | 1；不含登录/验证，确认服务器与本地副本后进入正确 ID |
| 已打开导出分区 → PNG / PDF / 项目 | 1 / 2 / 1；PDF 两次是打开规格预览、确认导出；PNG 特殊选项另计 |
| 已打开材料分区 → 完整材料文本 | 1；剪贴板拒绝则展示可选择的同一份完整文本 |
| 已选投稿来源 → 提交审核 | 许可勾选 + 提交 2；标题输入另计，确认针对当前云端版本 |
| 审核队列 → 批准 | 选对象 + 批准 2；必须先填写理由，完整材料在两次操作之间读取 |
| 批次整图 → 已保存草稿 | 选文件 + 开始生成 2；不含系统选择操作，成功结果自动逐项保存 |
| 批次草稿 → 公开 | 逐项勾选 + 打开清单 + 勾选权利确认 + 确认公开；不自动选择或发布 |

## 逐页保留控件的用途

| 页面 | 保留动作及用户问题 |
| --- | --- |
| 全站导航 | 首页/工作台/设计/豆社/账号承担五个主要任务；手机“更多入口”提供色板、帮助和隐私；跳到主内容服务键盘用户 |
| 首页 `/` | 选图是主动作；空白起稿支持无原图绘制；最近设计继续具体作品；全部设计访问完整库；豆社入口找作品；折叠教程服务首次使用 |
| 工作台 `/app` | 预览/编辑/跟拼切换制作阶段；参数/用色/导出分区减少堆叠；高级选项包含低频处理；裁剪与重绑恢复生成源；保存用于立即落盘和失败重试；更多操作容纳重新上传/分享等次级任务 |
| 工作台画布 | 缩放/平移/复位用于定位；网格、板缝、色号控制阅读；画笔/橡皮/吸色/填色和撤销/重做用于修补；跟拼标记/颜色过滤/进度重置服务实际拼装；退出沉浸恢复原任务焦点 |
| 设计 `/designs` | 主按钮直达图纸；每张图纸管理入口保留重命名/删除/投稿；删除需确认；读取/下载/进度失败分别重试，不将失败伪装为空库；新建不会覆盖旧设计 |
| 色板 `/palettes` | 品牌/系列/规格/套装筛选真实色板；来源版本按需展开；指定图纸使用需返回确认且可撤销；自定义色板增改删服务已有领域，冲突保留输入并提供刷新/重新登录 |
| 豆社 `/community` | 真实查询/筛选/排序和游标翻页；清除筛选恢复空结果；详情链接进入作品；投稿/我的投稿入口管理自己的公开内容 |
| 作品 `/community/[id]` | 用这张制作创建私人副本；点赞可取消；评论发布/时限内编辑/删除；举报在分类确认后发送；返回列表保留上下文；版本信息为次级内容 |
| 投稿 `/community/submit` | 可信云端选源、修改公开标题、正式标签和未勾选许可；提交冻结版本；重试只确认原请求/原草稿；重新载入来源用于确定版本冲突；返回设计/我的投稿保留退出路径 |
| 我的投稿 `/community/mine` | 草稿提交；本次修订单独撤回；整件撤回明确隐藏公开版；修改重提沿稳定作品身份；历史按需展开；未知结果只能重试原动作，不能切换撤回范围 |
| 登录 `/login` | 登录、显示/隐藏密码、注册/找回密码；安全回跳保留原任务，但不自动重放内容操作 |
| 注册 `/register` | 创建账号、显示/隐藏密码、返回登录；验证是后续明确步骤，不伪报完成 |
| 找回/重置 `/forgot-password`、`/reset-password` | 请求重置、设置新密码、返回登录；防枚举文案与单次令牌语义不变 |
| 验证 `/verify-email` | 验证状态、重新发送或返回账号/登录；失效有恢复入口，不测试提权 |
| 账号 `/account` | 资料保存、验证邮件、密码修改、退出、注销；危险动作确认并在请求中禁止关闭；读取/退出失败不伪装成功 |
| 隐私 `/privacy` / 同意横幅 | 同意、拒绝、撤回和清除失败重试；撤回即时停采，服务器确认前不能重新同意；无跨页协调能力保持关闭 |
| 帮助 `/help`、关于 `/about` | 常见问题按需展开；制作、隐私与源码入口提供可执行下一步，无装饰性假操作 |
| 社区规则/版权申诉 | 阅读具体边界、返回豆社与正式联系入口；法律文案仍需专业审核，本轮不宣称法律验收 |
| 分享 `/s/[token]` | 阅读真实只读规格/图纸；开始新制作；不向访客暴露私有编辑入口，保留失效提示 |
| 审核 `/admin/reviews` | 选中修订、对照当前公开版、填写理由、批准/驳回；队列无默认对象；刷新冲突不丢未确认写请求 |
| 作品管理 `/admin/works` | 查找具名作品、看冻结材料和计数、精选/取消精选、锁/解锁评论、下架/恢复；后两者再次确认，恢复不能绕过批准历史 |
| 评论 `/admin/comments` | 选待审评论、核查正文/上下文、填写理由、公开/隐藏；公开评论的举报处置见举报页 |
| 举报 `/admin/reports` | 选案件、核对举报版本与当前材料、受理/结案/驳回；隐藏当前评论或定位作品是独立内容处置，不把结案冒充下架 |
| 标签 `/admin/tags` | 创建/查找/改名/排序/停用；合并选具名目标并再次确认，冲突不能误报成功 |
| 人员 `/admin/users` | 搜索并选择账号、理由/目标 userId 确认、暂停/恢复/角色调整；禁自身治理和最后管理员破坏，注销身份不反查 |
| 规则 `/admin/rules` | 复制当前完整词表编辑、增删字面规则、明确确认整表替换；冲突先读取新版本，不支持输入正则或政治分类 |
| 官方批次 `/admin/batches` | 选文件/统一参数/逐项覆盖/可选裁剪；暂停/取消/单项重试控制资源；逐项预览及完整图纸检查；历史主动恢复；发布清单再确认；未知响应同键恢复 |
| 分析 `/admin/analytics` | 常用日期/事件/维度筛选，低频高级筛选展开；趋势/漏斗和数据表提供不同阅读方式；长期能力下降明确标注 |
| 审计 `/admin/audit` | 条件查找、稳定翻页、选择事件查看白名单前后状态；只读，无编辑/删除按钮 |
| 系统 `/admin/system` | 读取真实版本、迁移与维护证据；读取失败重试；没有恢复备份/部署按钮，备份未接入不显示正常 |

## 环境边界

五宽度、键盘、短视口、安全区与 reduced-motion 是本地浏览器模拟。系统文件选择器、真机软键盘、打印尺量、生产数据/部署/备份未验证。实际已通过的范围和仍在执行的门禁以 verification.md 为准。
