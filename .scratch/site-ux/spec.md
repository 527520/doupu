## 设计方向与自检

主要受众年轻女性，主要场景为手机上选图、修补、跟拼和寻找喜欢的作品。每页一个显著主动作；可靠默认结果自动完成；低频设置和危险操作按需展开，不把安全确认藏掉。

色彩：奶油白 #f8f7f4、莓果红 #a83f68、墨紫 #302938、丁香紫 #756a8c、鼠尾草绿 #1e794c、砖红 #b44935。标题宋体/现有 serif，正文沿用清晰自托管黑体/系统无衬线；数字编号只在确有用处时等宽。视觉签名是实际图纸及实际用色色带，不做新装饰图样、不使用原型示例花束冒充作品。

布局选择：桌面清晰工作区，手机单列任务流；首页先选图及最近任务，图纸优先于说明；后台对象队列→内容→处置。对比后拒绝把所有页面套成大色块说明卡片，也不为了照搬桌面稿破坏已验证的手机沉浸工作区。

```
首页       选图主动作 → 最近制作 → 豆社作品
工作台     图纸/模式 → 常用调整 → 按需导出与高级设置
内容详情   实际作品 → 用这张制作 → 互动/次级操作
后台       对象队列 → 选中内容 → 有理由的处置
```

## 用户可观察验收

- 首页展示真实最近设计及公开精选/最新；没有则诚实空态，不伪造推荐。
- 选图自动整图首版，可选裁剪确认自动更新；手工修改、失败、取消与撤销保护不退化。
- 设计卡片一次主操作进入指定设计，先确保本地可用；用现有跟拼进度推导合适入口，不新增持久化视图模式。
- 豆社分页不丢筛选；引用成功后打开独立本地副本；认证后回上下文，但不自动执行发布、举报或同意。
- 投稿来源可选择/预填，不暴露可编辑内部 ID；真实预览/作者、未勾选许可；我的投稿有可执行下一步。
- 下载、材料、色板入口清晰；打印比例/分片提示和真实规格规则不变；重映射可撤销。
- 公共/账号/认证/分享页面一致且权限不变；手机能稳定找到色板、帮助、隐私。
- 后台全部现有模块可实际完成任务；先对象后表单；真实版本校验藏在内部而非删除；理由、角色隔离、高风险确认保留；不自动勾选发布。
