# 05 标签与版本化治理规则

Status: ready-for-human

Blocked by: 03

## Outcome

正式标签可治理，评论使用不可变词表版本和结构规则作明确伤害/色情/骚扰/垃圾风险分流，不自动处罚用户。

## Tracer Bullet

发布一个规则版本后，含高风险字面词的评论进入 pending_review；模糊词和政治内容不因词表被拦截，历史规则版本不可修改。

## Acceptance Tests

- 标签创建、改名、排序、停用与合并迁移。
- 规则字面匹配、分类、风险级别、版本不可变和正则拒绝。
- 链接数、控制字符、重复字符、短期重复文本和频率规则。
- moderator/admin 权限差异及完整审计。
