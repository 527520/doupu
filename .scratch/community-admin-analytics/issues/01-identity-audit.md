# 01 身份角色、账号状态与审计

Status: ready-for-human

## Outcome

账号状态和角色在每次会话解析时生效；CLI 可安全授予首位管理员；暂停、角色变更与匿名化都有审计和最后管理员保护。

## Tracer Bullet

一个 active user 的会话可通过 user 权限检查；同一会话在账号被暂停后立刻失效，审计记录不含邮箱全文或正文。

## Acceptance Tests

- 角色矩阵、401/403、暂停登录、会话撤销、公开 ID 和邮箱脱敏。
- 并发降级/暂停最后管理员只允许一个安全结果。
- 匿名化删除私人数据与点赞、软删除评论并保留公开作品和去身份治理事实。
- CLI 要求 userId、规范化邮箱、理由和显式确认，不存在 HTTP 提权入口。
