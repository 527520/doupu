# ADR-0014: 明确同意后的第一方 PostgreSQL 分析

- Status: accepted
- Date: 2026-09-04

豆谱只在访客明确同意后创建匿名分析身份并接收严格枚举的事件，原始事件保存 90 天、去标识日聚合保存两年。选择 PostgreSQL 内建采集而非第三方平台，是为了让撤回能够删除可关联原始数据并保持数据边界可审计；代价是 90 天外只提供总量和单维趋势，且跨日 UV 不作虚假相加。

## 2026-09-05：跨标签页与失败恢复

同源 Web Locks 串行处理同意请求直到响应 Cookie 落地；撤回在等待锁前即将现有偏好 Cookie 标为 `withdrawn` 并停采。grant 响应不写可读偏好 Cookie，避免旧响应推翻新撤回；明确同意/已保存同意恢复后还必须完成本页初始化才能采集，无 Web Locks 的环境保持关闭。请求有界超时，撤回未确认则持续停采并提供原请求重试。

撤回按可用 HttpOnly 访客令牌立即删除可关联原始事件及身份关联。若 grant 提交后响应丢失，服务端可能留下客户端不可访问、无事件且无账号关联的随机哈希空行；它不等于可关联使用数据，一天未使用后由日维护再次确认无事件/关联并清理。不声称表的所有物理行都在撤回瞬间归零。
