# ADR-0017: 官方批量生成保持在浏览器本地

- Status: accepted
- Date: 2026-09-04

官方批次复用可实例化的浏览器 Worker，最多并发两个任务，并把每个成功结果立即保存为服务器端官方草稿；原图、文件名和裁剪源始终不上传。与服务端图片队列相比，这保留了 D13/D37 的隐私边界并避免新增服务，但刷新后只能恢复已保存草稿，不能恢复尚未生成的本地文件任务。

生成结束通过独立 `finish` 动作记录完成时间及未成功数量，不依赖发布。完成或取消后，仍持有本地文件的失败/取消项可重新进入 running 后单独重试；草稿发布只改变明确勾选的修订，不改变批次生成状态。创建请求期间锁定文件集合并防止重复启动；晚到的恢复响应不得覆盖新选择。发布与下架共用 work → revision 锁序。
