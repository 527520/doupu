# ADR-0016: 账号匿名化与公开作者身份分离

- Status: accepted
- Date: 2026-09-04

公开作者使用随机不可枚举 ID 和冻结显示名，内部用户 ID 永不进入公开输出。账号注销不删除已经公开的作品，而是不可恢复地删除凭据和私人数据、移除点赞、软删除评论并把保留的治理事实去身份化；这保住公开引用的完整性，也避免用可登录身份永久绑定历史内容。

所有账号关联写入在事务内取得用户 `NO KEY UPDATE` 锁并重验 active，不能把请求开始时的会话身份当作提交时的许可。角色、暂停、注销和 CLI 共用 `doupu:user-governance` 事务咨询锁，先管理锁、再用户锁、再作品与修订/评论锁。注销完成后，陈旧请求不得重建凭据、私人数据、互动或审核身份关联；发信不持数据库锁，令牌暂存与激活各自重新校验。必要治理事实保留，但操作者、审核人、处置人、精选人等身份关联置空。

注销同时撤回本人非官方的未发布稿件；已有公开版保持公开，不把待审稿件在注销后继续批准。跨操作者幂等响应中携带旧内部/公开作者 ID 的缓存整条清除，不能仅清理主表而保留旧身份副本。
